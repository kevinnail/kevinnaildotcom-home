# kevinnail.com

My personal website — a hub for everything I like to do for fun and work: mushroom cultivation/ foraging, astronomy & astrophotography, music, glass work, and software.

This is not a template or a project meant for others to run — it's my own site, kept public simply because there's nothing proprietary in it.

## Sections

- **Home** — landing hub linking out to each part of my world
- **Coding Portfolio** (`/projects`) — dev projects, writeups, and links
- **Astrophotography** (`/astrophotography`) — photo gallery
- **Good Morning Mushrooms** — mushroom cultivation (Instagram)
- **Music** — drumming (Instagram)
- **Stress Less Glass** — glass business (external site)

## Stack

- [Vite](https://vitejs.dev/) 6
- [React](https://react.dev/) 18 + [React Router](https://reactrouter.com/) 7
- [Tailwind CSS](https://tailwindcss.com/) v4
- [react-helmet-async](https://github.com/staylor/react-helmet-async) for per-page SEO tags

Static site, no backend or API — all content lives in `src/data/` as plain JS.
